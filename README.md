# Bitbucket Cloud Plugin for Jenkins

A Jenkins plugin for Bitbucket Cloud, modeled on the [Jenkins GitLab Plugin](https://github.com/jenkinsci/gitlab-plugin).

> 🚧 **Work in progress.** This plugin is being built using the GitLab Plugin as a reference. Development is happening in a separate worktree/branch; this README will be updated as features land.
>
> 🚧 **개발 중입니다.** GitLab Plugin 을 참조하여 만들고 있습니다.
